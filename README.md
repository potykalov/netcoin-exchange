
# Неткоин — учебное приложение для обмена внутренней валюты

**Неткоин** — учебное веб-приложение, в котором пользователи могут управлять балансом внутренней валюты, конвертировать средства, переводить их другим пользователям и вести список избранных получателей.

Приложение состоит из страницы входа и регистрации и личного кабинета. Клиентская часть взаимодействует с серверным API и отображает результаты пользовательских операций.

Проект выполнен индивидуально в рамках дипломной работы по курсу **«Основы JavaScript»** Нетологии.

## О проекте

Неткоин разработан на основе [дипломного задания Нетологии](https://github.com/netology-code/bjs-diplom).

В исходном шаблоне уже были предоставлены HTML- и CSS-интерфейс, серверная часть и классы для работы с API и DOM.

**Моя задача — связать готовые компоненты интерфейса с серверным API:** передавать данные из форм на сервер, обрабатывать результаты запросов и обновлять отображаемую информацию.

Для выполнения задания реализовал JavaScript-логику в двух файлах:

- [`public/loginPage.js`](public/loginPage.js) — вход и регистрация.
- [`public/homePage.js`](public/homePage.js) — личный кабинет, операции с балансом, курсы валют и избранные получатели.

Готовые классы `ApiConnector`, `UserForm`, `MoneyManager`, `ProfileWidget`, `FavoritesWidget`, `RatesBoard` и `LogoutButton` использовал для взаимодействия с сервером и интерфейсом. Их разработка не входила в мою часть задания.

Приложение работает с учебными данными и внутренней валютой. Оно не предназначено для реальных финансовых операций.

## Мой вклад

### 1. Регистрация и авторизация

В файле `loginPage.js` реализовал обработку действий пользователя на странице входа и регистрации.

- Создал экземпляр предоставленного класса `UserForm`.
- Подключил обработчики отправки форм через `loginFormCallback` и `registerFormCallback`.
- Связал данные форм с методами `ApiConnector.login()` и `ApiConnector.register()`.
- Реализовал проверку результата запроса.
- Добавил отображение сообщения об ошибке при неуспешном входе или регистрации.
- Настроил перезагрузку страницы после успешного выполнения запроса для перехода к авторизованному состоянию.

### 2. Личный кабинет пользователя

В файле `homePage.js` реализовал взаимодействие компонентов личного кабинета с серверным API.

- Подключил обработку выхода из учётной записи.
- Добавил запрос информации о текущем пользователе и отображение профиля.
- Реализовал загрузку курсов валют и отображение полученных данных в таблице.
- Связал формы пополнения, конвертации и перевода средств с соответствующими методами API.
- Добавил обновление отображаемого баланса после успешных операций.
- Реализовал вывод сообщений об успешных действиях и ошибках, возвращённых сервером.

### 3. Операции с балансом

Подключил три пользовательских сценария к серверному API:

**Пополнение счёта.** Данные из формы передаются в `ApiConnector.addMoney()`. При успешном ответе обновляется информация профиля и отображается сообщение о пополнении.

**Конвертация валют.** Данные о сумме, исходной и целевой валютах передаются в `ApiConnector.convertMoney()`. После успешного запроса обновляется отображаемый баланс.

**Перевод другому пользователю.** Данные о получателе, валюте и сумме передаются в `ApiConnector.transferMoney()`. Результат операции отображается пользователю, а при успешном ответе обновляется профиль.

Проверки достаточности средств, расчёт конвертации и изменение балансов выполняются предоставленной серверной частью.

### 4. Работа с избранными получателями

Реализовал взаимодействие списка избранных пользователей с API и формой перевода средств.

- Добавил начальную загрузку списка избранных через `ApiConnector.getFavorites()`.
- Связал добавление пользователя с методом `ApiConnector.addUserToFavorites()`.
- Связал удаление пользователя с методом `ApiConnector.removeUserFromFavorites()`.
- После успешного изменения списка обновил таблицу избранных.
- Добавил синхронизацию списка избранных со списком получателей в форме перевода.
- Реализовал отображение сообщений о результате добавления и удаления пользователя.

## Функциональность

### Вход и регистрация

Пользователь может создать учётную запись или войти с существующими данными.

После успешной авторизации открывается личный кабинет. При неуспешном запросе отображается сообщение об ошибке, полученное от сервера.

### Личный кабинет

В личном кабинете пользователь может:

- Просматривать идентификатор, логин и баланс.
- Просматривать курсы валют.
- Пополнять баланс.
- Конвертировать валюту.
- Переводить средства другому пользователю.
- Добавлять и удалять избранных получателей.
- Выходить из учётной записи.

### Валюты

В приложении используются четыре валюты:

| Код | Название |
| --- | --- |
| `RUB` | Российский рубль |
| `EUR` | Евро |
| `USD` | Доллар США |
| `NTC` | Внутренняя валюта «Неткоин» |

Серверная часть предоставляет курсы валют и выполняет расчёты при конвертации.

### Избранные получатели

В личном кабинете можно добавлять пользователей в список избранных и удалять их из него.

После изменения списка избранных обновляются как таблица пользователей, так и выпадающий список получателей в форме перевода.

Добавление пользователя в избранное само по себе не подтверждает существование получателя в системе: возможность перевода проверяется сервером при выполнении операции.

## Технические решения

### Связь готового интерфейса с API

Ключевая задача проекта — организовать взаимодействие между готовыми UI-классами и методами `ApiConnector`.

Классы интерфейса передают введённые пользователем данные через callback-свойства. В файлах `loginPage.js` и `homePage.js` этим свойствам назначены функции, вызывающие соответствующие методы API.

После получения ответа проверяется результат операции и вызывается метод обновления интерфейса или отображения сообщения.

Такой подход позволяет использовать уже существующие компоненты без изменения их внутренней реализации.

### Обработка результатов запросов

Для входа и регистрации реализована проверка свойства `success` в ответе сервера.

При успешном результате вызывается `location.reload()`. При неуспешном — соответствующий метод отображения ошибки формы.

При выполнении операций с балансом в зависимости от результата запроса обновляется профиль либо отображается сообщение об ошибке.

### Обновление отображаемого баланса

После успешного пополнения, конвертации или перевода сервер возвращает обновлённые данные пользователя.

Для их отображения используется метод:

```javascript
ProfileWidget.showProfile(response.data);
```

Благодаря этому информация в личном кабинете обновляется после операции без необходимости вручную рассчитывать баланс на клиенте.

### Синхронизация избранных и формы перевода

После загрузки, добавления или удаления избранного пользователя обновляются два компонента:

1. Таблица избранных пользователей.
2. Выпадающий список получателей в форме перевода.

Для этого используются методы предоставленных UI-классов:

```javascript
favoritesWidget.clearTable();
favoritesWidget.fillTable(response.data);
moneyManager.updateUsersList(response.data);
```

Обновление обоих компонентов выполняется на основе данных, возвращённых сервером.

### Загрузка курсов валют

При открытии личного кабинета выполняется запрос курсов валют через `ApiConnector.getStocks()`.

Полученные данные передаются компоненту `RatesBoard` для отображения в таблице.

В текущем коде также предусмотрен повторный вызов функции загрузки курсов по таймеру.

## Технические задачи и решения

### 1. Обработка успешного и неуспешного входа

**Задача**

Связать готовую форму авторизации с серверным API и показать пользователю результат попытки входа.

**Решение**

Назначил обработчик свойству `loginFormCallback` класса `UserForm`.

В обработчике передал данные формы в `ApiConnector.login()` и добавил проверку свойства `success` в ответе сервера.

При успешном ответе выполняется перезагрузка страницы. При неуспешном — ошибка передаётся в `userForm.setLoginErrorMessage()`.

Аналогичную обработку реализовал для регистрации.

**Результат**

Пользователь получает сообщение при неуспешной попытке входа или регистрации и переходит к авторизованному состоянию после успешного запроса.

**Реализация:** [loginPage.js](public/loginPage.js)

### 2. Обновление профиля после операций с балансом

**Задача**

После пополнения, конвертации или перевода средств необходимо отображать актуальный баланс пользователя и результат выполненной операции.

**Решение**

Связал callback-свойства `MoneyManager` с соответствующими методами `ApiConnector`.

После успешного ответа сервера передаю обновлённые данные пользователя в `ProfileWidget.showProfile()`.

Для уведомления пользователя вызываю `moneyManager.setMessage()` с признаком успешного выполнения операции и текстом сообщения.

При неуспешном ответе отображается ошибка, полученная от сервера.

**Результат**

После выполнения операций информация о балансе в личном кабинете обновляется на основании ответа сервера, а пользователь видит результат действия.

**Реализация:** [homePage.js](public/homePage.js)

### 3. Согласованное обновление избранных получателей

**Задача**

После добавления или удаления избранного пользователя необходимо обновить одновременно таблицу избранных и список доступных получателей в форме перевода.

**Решение**

В обработчиках `addUserCallback` и `removeUserCallback` реализовал вызов соответствующих методов API.

При успешном ответе очищаю и повторно заполняю таблицу избранных, затем передаю полученные данные в `moneyManager.updateUsersList()`.

**Результат**

После изменения избранных получателей оба компонента интерфейса отображают список, возвращённый сервером.

**Реализация:** [homePage.js](public/homePage.js)

## Установка и запуск

Для локального запуска необходимы Node.js и npm.

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/potykalov/netcoin-exchange.git
```

### 2. Перейдите в каталог проекта

```bash
cd netcoin-exchange
```

### 3. Установите зависимости

```bash
npm install
```

### 4. Запустите сервер

```bash
npm start
```

После запуска приложение будет доступно по адресу:

http://localhost:8000

Для остановки сервера нажмите `Ctrl + C` в терминале.
