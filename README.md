
# Неткоин — управление внутренней валютой

Неткоин — учебное веб-приложение для управления балансом внутренней валюты, конвертации средств и переводов между пользователями.

Приложение включает регистрацию, авторизацию, личный кабинет, просмотр курсов валют и управление избранными получателями.

Проект выполнен индивидуально в рамках дипломной работы по курсу «Основы JavaScript» Нетологии.

## Основные возможности

- Регистрация и авторизация пользователей.
- Просмотр профиля и текущего баланса.
- Отображение курсов валют.
- Пополнение баланса.
- Конвертация внутренней валюты.
- Переводы средств другим пользователям.
- Добавление и удаление избранных получателей.
- Отображение результатов операций и сообщений об ошибках.

## Мой вклад

Проект разработан на основе [дипломного задания Нетологии](https://github.com/netology-code/bjs-diplom).

В исходном шаблоне были предоставлены HTML- и CSS-интерфейс, серверная часть, API-клиент и готовые классы пользовательского интерфейса.

Моя задача заключалась в связывании предоставленных компонентов интерфейса с серверным API и реализации обработки пользовательских действий.

В ходе выполнения работы я:

- Реализовал обработку форм регистрации и авторизации.
- Связал формы с соответствующими методами API-клиента.
- Добавил обработку результатов запросов и отображение ошибок.
- Реализовал получение и отображение информации о текущем пользователе.
- Подключил загрузку и отображение курсов валют.
- Связал формы пополнения, конвертации и перевода средств с серверным API.
- Добавил обновление отображаемого баланса после успешных операций.
- Реализовал взаимодействие списка избранных пользователей с API.

Основная самостоятельная реализация находится в файлах `loginPage.js` и `homePage.js`.

Проверки достаточности средств, расчёт конвертации и изменение балансов выполняются предоставленной серверной частью.

## Технологии

**Моя реализация:** JavaScript, callback-функции, обработка асинхронных ответов, взаимодействие с API.

**Предоставленные компоненты:** API-клиент, DOM-компоненты и классы пользовательского интерфейса.

**Предоставленная серверная часть:** Node.js, Express, lowdb.

## Техническая реализация

### Регистрация и авторизация

Для обработки действий пользователя используются callback-свойства предоставленного класса `UserForm`.

В файле `loginPage.js` реализовал обработчики форм регистрации и авторизации, вызывающие соответствующие методы `ApiConnector`.

После получения ответа сервера проверяется результат выполнения операции.

При успешной авторизации выполняется переход к авторизованному состоянию приложения. При ошибке пользователю отображается соответствующее сообщение.

**Реализация:** [loginPage.js](public/loginPage.js)

### Взаимодействие личного кабинета с API

В файле `homePage.js` реализовал обработку пользовательских действий и взаимодействие готовых компонентов личного кабинета с серверным API.

Подключил получение данных пользователя, загрузку курсов валют, финансовые операции и управление избранными получателями.

После выполнения запросов соответствующие компоненты интерфейса обновляются на основе ответа сервера.

**Реализация:** [homePage.js](public/homePage.js)

### Обновление баланса после операций

Для пополнения, конвертации и перевода средств используются предоставленные методы `ApiConnector`.

После успешного выполнения операции сервер возвращает обновлённые данные пользователя.

Для их отображения используется метод предоставленного компонента:

```javascript
ProfileWidget.showProfile(response.data);
```

Таким образом, информация о балансе обновляется на основании ответа сервера.

Расчёт баланса и выполнение финансовых операций осуществляются на серверной стороне.

### Синхронизация избранных получателей

При добавлении или удалении избранного пользователя необходимо обновить два элемента интерфейса:

- Таблицу избранных пользователей.
- Список получателей в форме перевода.

После успешного запроса обновлённые данные передаются соответствующим UI-компонентам.

Для этого используются методы предоставленных классов:

```javascript
favoritesWidget.clearTable();
favoritesWidget.fillTable(response.data);
moneyManager.updateUsersList(response.data);
```

Это позволяет отображать актуальный список получателей в разных частях приложения.

## Установка и запуск

Для локального запуска необходимы Node.js и npm.

**1. Клонируйте репозиторий**

```bash
git clone https://github.com/potykalov/netcoin-exchange.git
cd netcoin-exchange
```

**2. Установите зависимости**

```bash
npm install
```

**3. Запустите сервер**

```bash
npm start
```

После запуска приложение будет доступно по адресу:

http://localhost:8000
